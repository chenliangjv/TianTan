# 天坛系统部署目录规划

服务器部署根目录：

```text
/epfs/TianTanSystem/
```

## 目录结构

```text
/epfs/TianTanSystem/
├── app/
│   ├── data-service.jar
│   ├── gateway-service.jar
│   └── scheduling-service.jar
├── frontend/
│   └── dist/
├── data/
│   ├── models/
│   ├── pointclouds/
│   ├── gaussians/
│   └── design-images/
├── tmp/
│   ├── data-service/
│   └── gateway/
├── logs/
│   ├── data-service/
│   ├── gateway/
│   └── scheduling-service/
└── config/
```

## 生产配置

三个后端服务启用 Spring Profile：

```bash
--spring.profiles.active=prod
```

生产配置默认使用：

```text
TIANTAN_STORAGE_ROOT=/epfs/TianTanSystem/data
TIANTAN_STORAGE_TEMP=/epfs/TianTanSystem/tmp
```

也可以通过环境变量覆盖，不需要重新打包：

```bash
export TIANTAN_STORAGE_ROOT=/epfs/TianTanSystem/data
export TIANTAN_STORAGE_TEMP=/epfs/TianTanSystem/tmp
export TIANTAN_DATA_SERVICE_URL=http://127.0.0.1:8081
export TIANTAN_SCHEDULING_SERVICE_URL=http://127.0.0.1:8083
```

## 构建与部署

在开发机执行：

```bash
pnpm --dir frontendcg build
mvn -f backend/pom.xml clean package -DskipTests
```

复制文件：

```text
frontendcg/dist/*                                      -> /epfs/TianTanSystem/frontend/dist/
backend/data-service/target/data-service-1.0.0-SNAPSHOT.jar
                                                        -> /epfs/TianTanSystem/app/data-service.jar
backend/gateway-service/target/gateway-service-1.0.0-SNAPSHOT.jar
                                                        -> /epfs/TianTanSystem/app/gateway-service.jar
backend/scheduling-service/target/scheduling-service-1.0.0-SNAPSHOT.jar
                                                        -> /epfs/TianTanSystem/app/scheduling-service.jar
```

首次部署前创建目录并授权给运行账号：

```bash
mkdir -p /epfs/TianTanSystem/{app,frontend/dist,data/{models,pointclouds,gaussians,design-images},tmp/{data-service,gateway},logs/{data-service,gateway,scheduling-service},config}
chown -R tiantan:tiantan /epfs/TianTanSystem
```

数据库仍通过 `backend/data-service/src/main/resources/application.yml` 的 MySQL 配置连接；生产环境建议将数据库用户名和密码改为环境变量或外部配置，不要把真实密码写入仓库。
